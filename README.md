# Code Academy — SEA TECHNOLOGIES MEDIA

A free online technology learning platform built with Flask, HTML, CSS, and JavaScript.

## About

Code Academy is built and maintained by **SEA TECHNOLOGIES MEDIA**.
It provides free, structured technology courses including HTML, CSS, JavaScript, Python, Git & GitHub, and Django.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Python (Flask)
- **Database:** JSON files
- **Hosting:** Render
- **Videos:** Google Drive
- **Forms:** Tally
